# Handoff: Tailored News — Personal Daily News Site

## Overview
"Tailored News" is a personal, mobile-first daily news front page for a single reader. It comprises **two views** sharing one design system:

1. **Daily Brief** (`index.html`) — the front page opened every morning. Three sections: *Politics & Current Events*, *Foreign Affairs*, *Sports*.
2. **History & Ideas** (`history-and-ideas.html`) — a weekly page of three longer, essayistic reads.

The aesthetic is a **personal broadsheet**: editorial and calm, warm paper + ink, a single sienna accent, strong typographic hierarchy, and a comfortable long-form reading measure. The design is intended to be produced by an automation pipeline that writes self-contained HTML files, so the markup uses **clear, consistent class names** that generated content can be dropped into.

## About the Design Files
The two files in this bundle (`index.html`, `history-and-ideas.html`) are **design references created in HTML** — self-contained prototypes showing the intended look, structure, and behavior. They are *not* necessarily meant to be shipped verbatim (though they are valid standalone pages).

The task is to **recreate these designs in the target environment** using its established patterns — or, if this is genuinely meant to remain a set of static, dependency-free HTML files generated by automation (which is the stated use case), the HTML here is directly usable as the canonical template and only needs to be wired into the generator. Choose whichever path matches the actual project:
- **Static-generator path (matches the brief):** treat these files as the canonical templates. The generator swaps the placeholder content (headlines, kickers, paragraphs, takes, date strings) into the existing DOM structure, one story per `<details>`.
- **App path:** rebuild the same visual system and structure using the codebase's framework/component library.

## Fidelity
**High-fidelity (hifi).** Final colors, typography, spacing, and interactions are all specified below and present in the files. Recreate the UI faithfully.

## Screens / Views

### 1. Daily Brief (`index.html`)

**Purpose:** the reader's morning front page.

**Layout:** single centered column (`.page`, max ~34rem measure), mobile-first, scaling up gracefully. Vertical stack: masthead → three `.section` blocks → colophon. A fixed theme toggle sits top-right.

**Masthead** (`<header class="masthead">`, centered):
- `.masthead-title` — "Tailored News".
- `.masthead-rule` — double-bar `<hr>`.
- `.masthead-meta` — flex row, space-between, wraps: `.masthead-date` ("Thursday, July 2, 2026") on the left; `.masthead-link` ("This week in History & Ideas →", href `history-and-ideas.html`) on the right. Mono, uppercase, faint; link is accent-colored with an on-hover bottom border.

**Section** (`<section class="section" id="politics|foreign-affairs|sports">`):
- `.section-header` containing `.section-label` (mono, uppercase, accent). A `::after` pseudo-element draws a 1px `--rule` line filling the remaining width.
- Section labels: "Politics & Current Events", "Foreign Affairs", "Sports".

**Story (all sections)** — a collapsible `<details class="story">`:
- `> summary` is a CSS grid `1fr auto`: left cell holds an optional `.story-kicker` (mono uppercase faint, e.g. "Capitol Hill") + `.story-headline`; right cell holds `.story-toggle` (a "+" that rotates 45° to an "×" when `[open]`). Default `list-style: none` and hidden webkit marker.
- `.story-body` holds the content, `padding-bottom` for breathing room.
- First `<details>` in each section has the `open` attribute; `.story:first-of-type` removes its top border.

**Signature component — Politics story card** (`.story--politics`):
1. `.facts` — 1–2 neutral paragraphs (`.story-body p`).
2. `.takes` — a **2-column grid** (`grid-template-columns: 1fr 1fr`, gap `0.9rem`) that collapses to a **single column at `max-width: 33rem`**. Contains:
   - `.take.take--left` — background `--take-left-bg`, `border-left` `--take-left`; `.take-label` reads "The Left-Leaning Take" in the slate color.
   - `.take.take--right` — background `--take-right-bg`, `border-left` `--take-right`; `.take-label` reads "The Right-Leaning Take" in the stone color.
   - Take labels are mono, uppercase, `0.64rem`, `letter-spacing: 0.15em`.
3. `.columnist` (optional) — an `<aside>` with `border-left: 1px solid var(--rule)`, italic serif body, and a `.columnist-byline` (mono, uppercase, faint, e.g. "Columnist — David French, The New York Times").

**Foreign Affairs & Sports stories** are the simple variant: `.story` → `.facts` only (headline + 1–2 paragraphs), no takes, no columnist. Sports includes a dedicated **English Football** item (`.story-kicker` "English Football") and a dedicated **Arsenal** item (`.story-kicker` "Arsenal"), plus one additional item.

**Colophon** (`<footer class="colophon">`): double top rule, mono uppercase faint, centered — brand line + link back to History & Ideas.

### 2. History & Ideas (`history-and-ideas.html`)

**Purpose:** weekly long-read page. Same masthead/type system, slightly more essayistic.

**Differences from the daily brief:**
- Masthead adds `.masthead-subtitle` ("A weekly reading from Tailored News", mono, uppercase, accent). `.masthead-meta` shows "Week of June 29, 2026" and a back-link "← Back to the daily brief" (href `index.html`).
- `.standfirst` — a centered italic serif intro paragraph under the masthead.
- Exactly **3** essays, each a `<details class="story">`. First has `open`; `.story:first-of-type` gets a `4px double var(--rule)` top border.
- Each essay summary uses `.story-domain` (mono, uppercase, accent) instead of a kicker — domain labels: **"Physical Sciences"**, **"History"**, **"Philosophy"**. (Others valid per brief: "Religion", etc.)
- `.story-body > p:first-child::first-letter` renders an accent-colored **drop cap** (`3.1rem`, float left).

## Interactions & Behavior

- **Collapse/expand:** native `<details>`/`<summary>`. First story per section is `open` by default. The `.story-toggle` "+" glyph rotates 45° (`transform: rotate(45deg)`, `transition: 0.2s ease`) when the parent is `[open]`, reading as an "×".
- **Links:** masthead link + colophon links navigate between the two pages via relative hrefs (`index.html` ⇄ `history-and-ideas.html`). Hover adds an accent bottom-border on the masthead link.
- **Theme toggle** (top-right `.theme-toggle` pill):
  - Defaults to the OS `prefers-color-scheme`.
  - On click, sets `data-theme="light|dark"` on `<html>`, toggling the explicit override, and persists it to `localStorage` under key **`brief-theme`**.
  - A pre-paint inline script in `<head>` reads `brief-theme` and applies `data-theme` *before* first paint to avoid a flash.
  - The button label (`.theme-toggle-label`) reflects the current theme ("Light"/"Dark"); a half-filled `.theme-toggle-dot` (a `linear-gradient` split circle) sits beside it.
  - Listens to `matchMedia('(prefers-color-scheme: dark)')` `change` to re-sync the label when no explicit choice is set.
- **Responsive:** single column throughout; base font bumps at `min-width: 720px`; politics takes go 2-col → 1-col at `max-width: 33rem`.

## State Management
Minimal, all client-side:
- **Theme:** `data-theme` attribute on `<html>` (`"light" | "dark" | absent`), persisted in `localStorage['brief-theme']`. When absent, OS preference governs.
- **Disclosure state:** handled natively by each `<details>` `open` attribute; no JS needed.
- No data fetching in the prototype — content is static placeholder markup the generator replaces.
